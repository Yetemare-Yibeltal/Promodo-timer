# Promodo Timer

An advanced, feature-rich Pomodoro timer and productivity workspace built with modern vanilla HTML5, CSS3, and JavaScript (ES6+ Modules).

## Core Capabilities

- Customizable timer modes (Pomodoro, Short Break, Long Break) with automatic cycles
- Persistent task manager with task estimation, tagging, and completion states
- Dynamic SVG circular ring visualizer for real-time progress updates
- Ambient sound generator and alarm audio integration
- Productivity analytics with daily streak counters and session histories
- Light and dark theme auto-detection with custom palette controls
- Zero third-party runtime dependencies

## Tech Stack

- **Structure:** HTML5 Semantic Elements
- **Styling:** Modular CSS Variables, Flexbox, CSS Grid
- **Scripting:** ES Modules (ES6+)
- **Storage:** LocalStorage API
